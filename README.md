# BDAG Community Node Dashboard

A Go dashboard for standalone BDAG node installations. The software is released
under GPL-3.0-or-later; third-party dependency notices are listed in
[THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

This source snapshot is based on commit
`5a4b99b08b59c05ad5dff081f9fdfaf4f9c847d7`. Runtime log and PID files from
the private development tree are intentionally excluded.

Build with a compatible Go toolchain using `go build .`. Stack release
instructions and packaged artifacts are published separately in the community
release repository.
